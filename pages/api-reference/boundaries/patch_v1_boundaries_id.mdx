# Update boundary

`PATCH /v1/boundaries/{id}`

## Parameters

| Name | Location | Required |
| --- | --- | --- |
| `X-Organization-Id` | header | Yes |
| `id` | path | Yes |

## Request body

```json
{
  "application/json": {
    "schema": {
      "$ref": "#/components/schemas/Record"
    }
  }
}
```

## Responses

- **200** Request completed.
- **403** Scope denied
- **503** Service unavailable

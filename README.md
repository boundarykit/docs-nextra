# BoundaryKit documentation

This Nextra portal includes workspace guides, REST operations, and webhook payloads. Each folder in `pages/` defines its sidebar in `_meta.js`.

Use Node.js 22. Run `npm ci` and `npm run build`. Serve the resulting `out/` directory at the root of a static host. The repository includes the OpenAPI specification in YAML and JSON and the source redirect inventory in `redirects.json`.
